# 👚 오늘 뭐입지?! — AI 의류 추천 시스템

당신의 스타일을 분석하고 TPO에 맞는 트렌디한 의류를 
추천해주는 AI 시스템.
사용자가 업로드한 의류 사진과 TPO(시간·장소·상황)를 입력하면, Segformer 세그멘테이션 → DETR 크롭 → RGB 벡터화 → 코사인 유사도 매칭을 거쳐 무신사·온더룩 스타일 DB에서 코디·상품을 추천하는 Streamlit 앱까지 구현을 완료하였다.

---

## 🎯 프로젝트 목적

입력한 옷 한 벌만으로도 TPO에 맞는 나머지 아이템을 골라 사용자에게 추천한다. 본 프로젝트는 다음을 수행한다.

1. 온더룩·무신사에서 스타일·상품 데이터를 수집·전처리한다.
2. Segformer·DETR 등 CV 모델로 의류 부위를 추출하고 벡터화한다.
3. TPO·카테고리별 스타일 DB와 코사인 유사도로 매칭한다.
4. Streamlit UI로 업로드 → 추천 결과(상품명·가격·이미지)를 제공한다.

## 🏗️ 시스템 아키텍처

```
┌─────────────────────────────────────────────────────────┐
│                  사용자 입력                             │

                           ↓
┌─────────────────────────────────────────────────────────┐
│             1️⃣ 이미지 전처리 계층                       │
│  • Segformer 세그멘테이션 (의류 부위 추출)              │
│  • DETR 객체 탐지 (배경 제거·크롭)                      │
│  • 이미지 정규화                                        │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│             2️⃣ 특징 추출 계층                           │
│  • 256×256 RGB 플래튼 → 196,608차원 벡터               │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│             3️⃣ 스타일 매칭 계층                         │
│  • TPO·카테고리별 스타일 벡터 DB 검색                   │
│  • 코사인 유사도 순위                                   │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│             4️⃣ 상품 추천 계층                           │
│  • 매칭 스타일과 유사한 상품 벡터 검색                  │
│  • CSV 메타데이터로 상품명·가격·이미지 연결             │
└─────────────────────────────────────────────────────────┘
                           ↓
┌─────────────────────────────────────────────────────────┐
│                  최종 추천 결과                          │
└─────────────────────────────────────────────────────────┘
```

## 🔑 핵심 기술

| 단계 | 기술 | 모델·방법 |
|------|------|-----------|
| 세그멘테이션 | Hugging Face Transformers | `mattmdjaga/segformer_b2_clothes` (18-class) |
| 객체 탐지·크롭 | DETR | `facebook/detr-resnet-50` (적응형 임계값) |
| 특징 표현 | RGB flatten | 256×256×3 → 196,608D |
| 유사도 | 코사인 유사도 | 스타일 DB → 상품 DB 2단계 매칭 |
| UI | Streamlit | `cloth_customization_refactored.py` |

세그멘테이션 모델 후보 4종 비교 결과 Segformer를 최종 채택하였다. (`notebooks/01_fashion_segmentation.ipynb`)

## 💡 사용 흐름

1. 의류 이미지 업로드 (PNG / JPG / JPEG)
2. 업로드 이미지 카테고리 선택 (top, bottom, shoes, hat 등)
3. 추천받을 카테고리 선택 (입력과 다른 카테고리)
4. TPO 선택 (여행, 카페, 전시회, 캠퍼스·출근, 급추위, 운동)
5. 유사 스타일·상품 매칭 결과 확인 (상품명, 가격, 썸네일)
